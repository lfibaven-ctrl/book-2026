# Fer Ibaven — Book 2026

Landing page estática, responsiva y lista para publicarse con **GitHub Pages**.

## Estructura

```text
book-landing/
├─ index.html
├─ styles.css
├─ script.js
├─ README.md
└─ assets/
   ├─ book-reference.png
   └─ favicon.svg
```

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub, por ejemplo: `book-2026`.
2. Sube todos los archivos de esta carpeta conservando la misma estructura.
3. En el repositorio, abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama **main** y la carpeta **/(root)**.
6. Guarda. En unos minutos aparecerá la dirección pública del sitio.

La URL normalmente será:

```text
https://TU-USUARIO.github.io/book-2026/
```

## Personalizar

- Textos y enlaces: `index.html`
- Colores, tamaños y composición: `styles.css`
- Animaciones y menú: `script.js`
- Imagen principal del book: reemplaza `assets/book-reference.png` sin cambiar el nombre.
